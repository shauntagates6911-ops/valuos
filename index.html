ValuOS

tiny hybrid OS — ASM · C · Rust

About

ValuOS is a small experimental operating system built from scratch using a bootloader in ASM, a kernel and drivers in C, and subsystems like the filesystem in Rust.

Repository

The source code is hosted on GitHub:

github.com/shauntagates6911-ops/valuos

Key components

  • bootloader.asm — boots the machine and jumps to the kernel
  • kernel.c — core OS logic and hardware control
  • drivers/ — screen, storage, and other hardware drivers
  • apps/ — user‑facing programs like Maps
  • filesystem.rust — ValuFS implementation in Rust
